# Dokumentasi - Sistem Pakar Buah Naga

## Diagrams

File-file HTML diagram UML & wireframe untuk dokumentasi skripsi.

| File | Keterangan |
|------|-----------|
| `diagrams/activity_diagrams.html` | Activity Diagram (alur aktivitas sistem) |
| `diagrams/use_case_diagram.html` | Use Case Diagram (aktor & fitur) |
| `diagrams/wireframes.html` | Wireframe UI halaman-halaman utama |
| `diagrams/pohon_keputusan.html` | Visualisasi interaktif pohon keputusan (SVG) |

### Cara Melihat
Buka file HTML langsung di browser (double-click), tidak perlu server.
